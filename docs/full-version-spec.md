# 《王冠》完整版 — 规格增补

主规格是 F1–F4 master prompt。本文只记录**在那之后追加的条目**，以及**冻结不做的清单**。

## F2 增补 — ORIGIN PICK（开局出身）

开局一个 modal，三选一出身，各配一句小说式引子：**猎户 / 边军 / 游侠**。
每种给一点点 `CONFIG` 层面的属性倾斜，用来**预告 F3 的骑弓枪三角**（猎户偏弓、边军偏枪、游侠偏骑）。

- 预算：半天。
- 落位：**F2 尾部**，不占 F2 主线（声望冻结 + 唯一胜利序列）的时间。
- 倾斜必须只走 `CONFIG`，不得引入新兵种或新公式。

## F3 增补 — BATTLE COMMANDS（已移除，底层未删除）

曾实现每场战斗两次阵中指令：**全线压上 / 稳住阵线 / 集火敌将**。
完整试玩后确认「阵中·传令」会打断一次投入后观看战斗展开的节奏，因此从玩家界面、
慢镜、舞台时间线、自动应答和表现层测试中移除。战前阵型选择保留，作为唯一战术决策层。

- **REMOVED-not-deleted**：`CONFIG.F3_COMMANDS`、`chooseBattleCommand()`、
  `applyF3BattleModifiers()` 以及 `battleScript.command` 兼容字段继续保留，便于未来实验恢复；
  当前舞台不读取该字段，也不生成任何中途交互。
- 现有内部确定性 fallback 保持不动，避免本次纯表现删除改变既有战斗公式、RNG 或结果。
- 若未来恢复，必须重新经过试玩证明它不会打断观战节奏，不能仅因管道仍在就默认开启。

## POST-LAUNCH（冻结，不要建）

- **实时侧视、玩家直接操作的战斗。**
  仅在上线后评论明确要求时才重新考虑。在此之前它不进任何 phase、不进任何 sprint、
  agent 提议也只进建议栏。

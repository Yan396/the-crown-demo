# 《王冠》完整版 — 规格增补

主规格是 F1–F4 master prompt。本文只记录**在那之后追加的条目**，以及**冻结不做的清单**。

## F2 增补 — ORIGIN PICK（开局出身）

开局一个 modal，三选一出身，各配一句小说式引子：**猎户 / 边军 / 游侠**。
每种给一点点 `CONFIG` 层面的属性倾斜，用来**预告 F3 的骑弓枪三角**（猎户偏弓、边军偏枪、游侠偏骑）。

- 预算：半天。
- 落位：**F2 尾部**，不占 F2 主线（声望冻结 + 唯一胜利序列）的时间。
- 倾斜必须只走 `CONFIG`，不得引入新兵种或新公式。

## F3 增补 — BATTLE COMMANDS（战斗指令）

每场战斗 2–3 个玩家指令：**全线压上 / 稳住阵线 / 集火敌将**。

- 实现为 `CONFIG` 层面的修正量，由玩家触发后**作为事件注入 battleScript**。
- **确定性必须保持**：指令是玩家输入，注入后脚本依旧是「已解算结果的回放」，
  watched 与 skipped 仍须落在同一个 `battle_end.survivors` 上。
- 与 F3 主线（骑弓枪三角）同期做，共用那一次平衡矩阵。

## POST-LAUNCH（冻结，不要建）

- **实时侧视、玩家直接操作的战斗。**
  仅在上线后评论明确要求时才重新考虑。在此之前它不进任何 phase、不进任何 sprint、
  agent 提议也只进建议栏。
